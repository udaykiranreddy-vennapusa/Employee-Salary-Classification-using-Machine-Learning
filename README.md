# 💼 Employee Salary Prediction using Machine Learning

## 📌 Overview

This project focuses on predicting employee salary categories using Machine Learning techniques. The objective is to analyze employee information, preprocess the data, train multiple machine learning models, and identify the best-performing model for salary prediction.

The project demonstrates the complete machine learning workflow, including data preprocessing, model training, evaluation, and performance comparison.

---

## 🚀 Features

- Data Collection and Exploration
- Data Preprocessing
- Feature Scaling using MinMaxScaler
- Exploratory Data Analysis (EDA)
- Train-Test Split
- Machine Learning Model Training
- Model Evaluation
- Performance Comparison

## 🤖 Machine Learning Algorithms

The following machine learning algorithms were implemented and evaluated:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Multi-Layer Perceptron (MLP Classifier)

---

## 📊 Data Preprocessing

The dataset was prepared using the following preprocessing techniques:

- Handling missing values
- Feature selection
- Data encoding
- Feature Scaling using MinMaxScaler
- Train-Test Split

---

## 📈 Model Evaluation

The trained models were evaluated using:

- Accuracy Score

The model performances were compared to determine the most suitable algorithm for employee salary prediction.
